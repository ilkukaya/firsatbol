# Sağlayıcı atıf (attribution) HTML'leri

Bir sağlayıcı resmî bir atıf HTML'i (logo + bağlantı) veriyorsa, onu bu klasöre
`<sağlayıcı-id>.html` adıyla kaydedin. Örnek: `firsatbufirsat.html`.

- Dosya varsa, o sağlayıcının verilerini gösteren HER sayfada metin yerine bu HTML gösterilir.
- Dosya yoksa standart metin gösterilir:
  "Fırsat bilgileri Fırsat Bu Fırsat tarafından sağlanmaktadır."
- Yalnızca yayıncı panelinde size verilen resmî kodu yapıştırın. `<script>` içeren kodlar
  güvenlik nedeniyle reddedilir (derleme uyarı verir ve metin sürümü kullanılır).
